# Auralis

Auralis 是这间人声练习室的英文名称，灵感来自 aural（听觉）与极光般流动的光感。名称搭配小写字标 `auralis`，表达专注、平静且有探索感的练习体验；产品界面保留中文，方便练习者理解音分、标准音与曲谱校对等操作。名称是本项目的设计选择，不构成商标注册或名称独占性的声明。

标志把字母 A 的上升轮廓、横穿其间的人声音高曲线与一条轻盈的轨道融合在一起：轮廓对应练习目标，曲线对应真实的声音，轨道对应持续进步。深夜蓝 `#0b101a` 为背景，冰青 `#6fe6e9` 表示实时声音和主要操作，柔紫 `#9c8dff` 用作标准音与辅助光感；保持低饱和、大留白和清楚的对比，让曲线始终是画面的中心。标志由项目原生 SVG 绘制，无外部图片或字体依赖。

## 资产

- `public/icon.svg`：192 × 192，深色圆角应用图标与浏览器图标。
- `public/logo-mark.svg`：64 × 64，透明背景标志，适合页面导航与小尺寸显示。
- `public/logo-lockup.svg`：280 × 72，透明背景的完整英文标志，适合深色背景。

应用名称使用 `Auralis`，视觉字标使用 `auralis`，说明文字使用 `VOCAL PRACTICE STUDIO`。保留图形四周至少半个字母 A 宽度的空白。字标可使用系统字体显示；图形在缩小后应保持原有比例，不增加阴影、描边或强烈的发光效果。

## 字体

界面英文采用自托管的 Space Grotesk variable Latin（字重 300–700），中文采用设备系统字体。字体文件为 `public/fonts/space-grotesk-latin-wght-normal.woff2`，22,288 字节，取自 Fontsource 发布的 [`@fontsource-variable/space-grotesk` 5.3.0](https://www.npmjs.com/package/@fontsource-variable/space-grotesk/v/5.3.0)；包内元信息对应 Space Grotesk、Latin、normal 与 300–700 变量轴。下载包 SHA-1 已与 npm 分发元信息核对，字体 SHA-256 为 `0640890476fc1198ab4de571fb658de443c4d85b66466ec09534a8737ab1ce9d`。保留上游完整 OFL 1.1 许可于 `public/fonts/OFL-Space-Grotesk.txt`，不通过运行时外部字体服务加载。
