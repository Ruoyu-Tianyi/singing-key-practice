# Auralis 使用指南

[打开练习室](https://singing-key-practice.vercel.app/#tuner) · [反馈问题](https://github.com/Ruoyu-Tianyi/singing-key-practice/issues/new/choose) · [开发路线](ROADMAP.md)

## 第一次练习

1. 用手机、平板或电脑浏览器打开上方 HTTPS 地址。点击“开启麦克风”，允许当前网站使用麦克风。练习时保持页面在前台。
2. 进入“标准音模唱”，选一个舒服的音，点击播放。先听完，再用自然音量唱“啊”或“呜”；使用耳机可以减少播放声音被再次识别。
3. 观察音名和曲线。模唱模式以所选目标音为准；实时音准仪以最近的标准音为准。音分为正表示偏高，为负表示偏低，±25 音分以内显示为唱准。
4. 若曲线容易断开或环境声也被识别，打开“收音设置”，使用自动校准或调整参数，边唱边看面板内预览。
5. 在“曲谱练习”选择短片段，先听示范，再调慢速度开始练习。4 拍预备后开始唱；完成后结合音准、覆盖率和换音偏差看反馈。

手机上目标音、播放和麦克风操作集中在曲线附近。使用放大按钮可扩大练习区；返回普通视图后仍保留当前目标音与曲谱。浏览器菜单中的“添加到主屏幕”可作为快捷入口，但当前版本不保证断网重新打开。

## 收音设置怎么调

先用“日常”预设，再根据实际效果微调。提高灵敏度会同时放大人声和背景声，不能代替降噪。

| 看到的现象                   | 可以尝试                                                      |
| ---------------------------- | ------------------------------------------------------------- |
| 唱歌时音量很小、曲线经常消失 | 靠近麦克风一些；适度提高输入增益，或降低音量门限。            |
| 停唱后仍有杂乱音高           | 降低环境噪声；适度提高音量门限或识别可信度。                  |
| 只在低音或高音时没有曲线     | 检查识别音域是否覆盖要唱的音；先恢复宽音域试唱。              |
| 音高变化显示迟缓             | 尝试较短分析窗口；低音可能更难稳定，需要结合实际声音选择。    |
| 手机发热或曲线不够流畅       | 将检测更新频率降到 20 或 10 次/秒，并关闭其他占用较高的应用。 |

“音高 Hz”表示声音高低，例如 A4 为 440 Hz；“检测更新频率”是每秒期望分析的次数；“音频处理采样率”由浏览器和设备决定。分析窗口越长，包含的声音片段越长，可能有利于低音识别，也可能增加响应时间。窗口时长不是实际听觉或跟唱延迟。

### 自动校准

1. 点击“自动校准”。保持安静 4 秒，让工具测量当前环境声音。
2. 环境采样后不会立即要求发声。准备好后点击“开始试唱”，用正常练习音量持续唱一个舒服的音 6 秒。
3. 推荐的增益与门限会填入表单并作用于预览。继续唱着微调，满意后点击“保存设置”。

校准失败时原参数不变。若提示环境声与试唱过于接近，可以减少噪声或调整距离后重试。校准只估计适合本次环境的分析参数，不测量声压、不改变硬件麦克风音量，也不代表音准评分。

设置面板内的参数是草稿：保存才用于正式练习；关闭会放弃未保存的更改。若麦克风是在面板内新开启的，关闭或保存时会停止这次收音；若原先已在主页面监听，关闭面板后会继续使用已保存参数监听。更换设备或环境后可以重新校准。

## 理解结果与练习记录

| 指标         | 含义                                                                                  |
| ------------ | ------------------------------------------------------------------------------------- |
| 音准命中率   | 在检测到有效音高的部分中，唱到目标音附近的比例。没有有效音高时显示“—”，不会当作唱准。 |
| 有效发声覆盖 | 应发声的曲谱时段中，检测到有效音高的比例。高命中率但低覆盖率可能只是少量音被识别。    |
| 换音平均偏差 | 依据发声或换音时机估计的时间偏差；连续同音不容易区分，只作节奏参考。                  |

“练习记录”保留最近 100 次完成的曲谱练习，提供最近 7 天概览。记录包括曲目、速度、移调、片段、时长和上述反馈；示范播放、自由模唱以及中途停止的曲谱练习不计入这份完成记录。循环练习每完成一遍可形成一条记录。

近 7 天概览只统计这些完成记录，与首页的今日监听时长分别计算。可以从记录载入当时的速度、移调与片段再练一遍；对应曲谱需仍在当前曲谱库中。

记录保存在当前浏览器，不包含录音。比较两次表现时，尽量使用相同片段、速度、移调和收音环境。这里的反馈用于自我练习，没有经过专业考试评分标定。

通过“导出记录”保存 JSON 备份，再用“导入记录”恢复。导入按记录 ID 合并并保留最近 100 次，不会把同一条记录重复计数；备份不包含曲谱和收音设置。如页面提示浏览器未能保存，请在关闭页面前导出记录。

## 导入歌曲

优先使用 MusicXML 或 MIDI 等数字曲谱。导入后先试听，再核对音高、休止和拍数；可以逐音修改，也可以从手动简谱开始。

| 来源              | 注意事项                                                                                      |
| ----------------- | --------------------------------------------------------------------------------------------- |
| MusicXML / MXL    | 取首个含音高的声部中的首个旋律 voice / staff；整首采用统一速度，反复按谱面读一遍。            |
| MIDI              | 取首个非打击乐、有音符的轨道，和弦及重叠音会简化为单旋律。                                    |
| 本工具导出的 JSON | 适合传递和备份单首曲谱；不是音频文件。                                                        |
| 简谱图片 / PDF    | 生成待校对的 OCR 文字，八度点、时值、歌词和页码都可能识别错误；确认后才导入。PDF 最多 10 页。 |
| 五线谱图片 / PDF  | 需连接 [Audiveris 服务](../server/README.md)，识别后仍需校对。线上网站本身不提供该服务。      |

单个文件最大 20 MB，模板最多 10,000 个音符。复杂总谱可先在制谱软件选出主唱旋律，导出为 MusicXML。

手机上的 `127.0.0.1` 指向手机自身，无法直接连接电脑本地的五线谱识别服务。可以在电脑完成识别和校对，导出曲谱 JSON，再传到手机导入。

## 常见问题

### 无法开启麦克风

确认页面是 HTTPS，且浏览器和系统都允许麦克风访问。曾经拒绝授权时，可在浏览器的网站权限中修改，再回到页面重试。若设备正在被其他应用占用，关闭占用应用后再试；若在聊天软件的内嵌浏览器中失败，可复制网址到独立浏览器打开。

### 点击播放没有声音

需要主动点击播放按钮。检查网页音量、设备音量和实际输出设备；连接蓝牙耳机时确认声音没有输出到另一台设备。回到页面后再次点击播放，不要依赖后台播放。

### 接电话、切换应用或锁屏后停止了

页面进入后台时会停止麦克风与播放。回到页面后主动重新开启；中断的练习需要重新开始。若麦克风被拔出或系统停止收音，先恢复设备连接，再按页面提示重试。

### 没唱歌也有曲线，或结果忽高忽低

先停止扬声器播放，换用耳机，并在安静环境用单一人声试唱。工具面向独唱单旋律，不进行伴奏分离；多人、混响和回传会影响结果。若仍异常，恢复收音默认值后重新校准。

### 练习数据不见了

数据属于当前浏览器和访问域名。换浏览器、换设备、进入另一域名或清理网站数据后，不会自动出现原记录。无痕模式与浏览器存储限制也可能影响保存。

迁移时，在旧地址逐首导出曲谱 JSON，并从练习记录中单独导出记录备份，再在新地址分别导入。收音参数需要在新设备重新设置或校准。曲谱 JSON 与记录备份互不包含，也不等同于完整网站备份。

## 数据与反馈

麦克风声音仅在本机实时分析，不录制、不上传。普通数字曲谱与简谱 OCR 在浏览器处理，首次 OCR 需下载引擎和语言资源；只有主动选择五线谱服务时，曲谱才会发送到填写的服务地址。应用没有账号、云备份或跨设备自动同步。

遇到问题可在应用帮助中点击“复制诊断信息”，先查看内容，再粘贴到 [GitHub 问题反馈](https://github.com/Ruoyu-Tianyi/singing-key-practice/issues/new/choose)。诊断包含应用版本、浏览器、音频支持和当前收音参数，不包含录音、曲谱内容或练习历史，也不会自动提交。同时写明设备、操作步骤、期望结果和实际结果；反馈会公开显示，不要附密码、令牌、私人录音或无权公开的整首曲谱。

发布前的验证范围和仍待实体设备实测的内容见 [验证记录](VERIFICATION.md)。路线图列出待开发方向，不代表这些能力已经上线，也不承诺固定发布日期或响应时限。
